# Cinder invariants register

This register links system promises to current tests. **UNCOVERED** means no
test currently proves the full stated property; related unit tests are not
treated as proof of a distributed or crash-safety claim.

| ID | Invariant | Evidence / coverage |
|---|---|---|
| INV-LWW-1 | A higher `(version, writer)` stamp wins; merge is deterministic and a stale value cannot replace a newer value. | Covered locally: `internal/store/versioned_test.go` (`TestVersionedNewerWins`, `TestVersionedStaleIgnored`, `TestVersionedTiebreakWriterHash`). Cross-replica behavior has selected partition/loss tests and 50-seed mixed-operation convergence in `internal/sim/sim_property_test.go` (`TestSimSeededMixedOperationsConverge`). This is bounded evidence, not exhaustive schedule coverage. See `CONSISTENCY.md`. |
| INV-TOMB-1 | A tombstone is not overwritten by a lower stamp and a stale delete does not erase a newer value. | Covered locally: `internal/store/versioned_test.go` (`TestVersionedStaleDeleteLoses`, `TestVersionedTombstoneWinsTies`). Within-grace deletes under churn are covered by `internal/sim/sim_property_test.go` (`TestSimChurnDeletesStayDeleted`, 50 seeds, leave/rejoin with crash-window deletes, rebalance, hint replay, and AE). The stale-replica resurrection risk after tombstone GC is reproduced by `internal/net/tcp/tombstone_resurrection_test.go` (`TestTombstoneResurrectionReproducedAfterGC`); the over-age anti-entropy fence is covered by `TestAntiEntropyRejectsReplicaPastTombstoneGrace`. Exact outage-age detection remains **UNCOVERED** because `JoinedAt` is not a durable last-seen timestamp. See `OPERATIONS.md`. |
| INV-CRDT-1 | Counter merge is commutative, associative, and idempotent; components do not decrease when merging. | Partially covered: `internal/counter/counter_test.go` (`TestGCounterMergeTakesMax`, `TestPNCounterValueAndMerge`, `TestPNCounterConcurrentIncrementsSurvive`); AE has delivery-loss/reorder/duplicate coverage in `internal/ae/counter_test.go`. Exhaustive algebraic/property testing is **UNCOVERED**. |
| INV-REBAL-1 | Local data is removed only when the required new holders have acknowledged migration; failed migration retains the source copy. | Covered by focused tests: `internal/shard/shard_test.go` (`TestLeavingMigratesAndRemoves`, `TestMigrationFailureKeepsLocal`, `TestTombstoneAndTTLMigrate`, `TestSingleCopyMigrates`) and TCP rebalance tests. `internal/sim/sim_property_test.go` (`TestSimRebalanceChurnPreservesAckedValues`) checks acknowledged values across leave/rejoin, crash-window quorum writes, and rebalance over 50 deterministic seeds. This is bounded evidence, not exhaustive schedule coverage. |
| INV-QUORUM-1 | A successful quorum write has acknowledgements from a majority of the ring-selected owners including the local primary. Replicated reads select the best observed LWW stamp but are availability-first and may return after fewer than RF positive versioned votes. | Unit-level quorum behavior: `internal/repl/repl_test.go` (`TestWriteQuorum`, `TestReadQuorumLWWAndRepair`); selected outage proof in `internal/sim/sim_property_test.go` (`TestSimQuorumAckSurvivesOneReplicaOutage`) and seeded churn in `TestSimRebalanceChurnPreservesAckedValues`. Cinder exposes no independent `R`; linearizability and universal read-after-quorum guarantees during changing membership/failures are **NOT PROVIDED**. See `CONSISTENCY.md`. |
| INV-WAL-1 | Recovery includes all writes durable under the configured acknowledgement/fsync policy and never silently accepts corrupt state. | Partial coverage: `internal/persist/wal_test.go` (`TestWALRoundTrip`, `TestWALTornTail`, `TestWALCorruptionDetected`, WAL v1/v2 upgrade and v3 counter golden/round-trip tests), `internal/persist/wal_fuzz_test.go` (`FuzzWALCounterStateRecord`), `internal/persist/manager_test.go` (torn-tail/corruption, counter WAL/snapshot/merge/response-loss recovery tests), `internal/persist/fsync_test.go` (`TestFsyncPolicyCrashRecovery`), `internal/net/tcp/counter_test.go` (`TestCounterPersistenceAcrossServerRestart`), and `internal/persist/crash_matrix_test.go` (`TestDurabilityCrashRecoveryMatrix`, 100 deterministic cases). The matrix explicitly syncs expected state before simulating restart; hardware power-loss behavior and loss of unsynced page-cache data remain **UNCOVERED**. Snapshot/compaction power-loss safety is also **UNCOVERED**. |
| INV-TTL-1 | An expired entry is not returned by reads and does not reappear through repair, hint replay, or anti-entropy. | Local expiry: `internal/store/versioned_test.go` (`TestVersionedTTLExpires`) and LRU tests. TTL is covered in read repair (`internal/repl/repl_sim_test.go`, `TestSimReadRepairPreservesTtl`) and hint expiry (`internal/repl/repl_test.go`, `TestHintTTLExpiry`). Cross-path clock-jump property testing is **UNCOVERED**. |
